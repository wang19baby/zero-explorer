# Zero Explorer - UI 设计文档

**版本**: v1.0  
**日期**: 2026-08-31  
**产品**: Zero Explorer  
**平台**: Windows 10/11  

---

## 一、设计方向

### 1.1 美学方向
**工业/功能优先** — 专注于功能性和数据密度，采用等宽字体元素和柔和色调。

### 1.2 装饰级别
**最小化** — 让排版和间距完成所有工作，避免不必要的装饰。

### 1.3 布局方法
**网格纪律** — 严格的列对齐，可预测的布局，适合多面板文件管理器。

### 1.4 颜色方法
**克制** — 1个强调色 + 中性色，颜色稀少且有意义。采用 Windows 10/11 系统蓝色作为主色调。

## 七、组件规范

### 7.1 按钮
- **高度**：32px
- **内边距**：8px 16px
- **圆角**：4px
- **字体**：14px, 500 字重

类型：
- **Primary**：蓝色背景，白色文字
- **Secondary**：白色背景，边框
- **Ghost**：透明背景，无边框

### 7.2 输入框
- **高度**：32px
- **内边距**：0 12px
- **圆角**：4px
- **边框**：1px solid #D1D1D1
- **聚焦状态**：蓝色边框 + 蓝色阴影

### 7.3 标签页
- **背景**：#F3F3F3
- **选中状态**：白色背景，底部蓝色边框
- **悬停状态**：白色背景

### 7.4 面包屑导航
- **位置**：Tab 上方
- **单击**：跳转到对应目录
- **双击**：切换为绝对路径输入框
- **输入路径 + Enter**：跳转到指定路径
- **Esc**：取消输入，恢复面包屑

### 7.5 文件列表
- **行高**：36px
- **列宽**：图标 32px，名称 1fr，类型 120px，大小 80px，修改时间 140px
- **悬停状态**：Primary Light 背景
- **选中状态**：Primary 背景，白色文字
- **列信息**：图标 + 名称 + 类型 + 大小 + 修改时间

## 八、布局系统

### 8.1 设计特点
- **无标题栏**：完全沉浸式体验，窗口控制通过系统手势或快捷键
- **无工具栏**：地址栏导航通过 `Ctrl+L` 唤起
- **侧边栏默认隐藏**：通过 `Ctrl+Shift+B` 切换显示

### 8.2 多面板布局
```
┌─────────────────────────────────────────────────────┐
│  ┌──────────────┬──────────────┐                    │
│  │  面板 1      │  面板 2      │  ← 无标题栏/工具栏  │
│  │  ┌────────┐ │  ┌────────┐ │                    │
│  │  │面包屑   │ │  │面包屑   │ │  ← Tab 上方       │
│  │  ├────────┤ │  ├────────┤ │                    │
│  │  │ 标签页  │ │  │ 标签页  │ │  ← Tab 下方       │
│  │  ├────────┤ │  ├────────┤ │                    │
│  │  │ 文件列表│ │  │ 文件列表│ │                    │
│  │  └────────┘ │  └────────┘ │                    │
│  └──────────────┴──────────────┘                    │
├─────────────────────────────────────────────────────┤
│  状态栏 (项目数量/选中状态/当前路径)                    │
└─────────────────────────────────────────────────────┘
```

### 8.3 侧边栏（默认隐藏）
```
┌──────────┬──────────────────────────────────────────┐
│          │                                          │
│  侧边栏   │  主内容区（多面板）                         │
│  (导航)   │                                          │
│  ┌──────┐│                                          │
│  │此电脑 ││  ← 磁盘空间进度条                         │
│  │标签   ││  ← 用户自定义的常用文件夹和标签              │
│  │最近   ││  ← 最近访问文件                           │
│  │空间   ││  ← Space 管理（切换/新建）                  │
│  └──────┘│                                          │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

**侧边栏功能**：
- **此电脑**：显示各磁盘及使用率进度条
- **标签**：用户自定义的常用文件夹和分类标签，支持添加/删除
- **最近访问**：最近打开的文件/文件夹，显示访问时间
- **空间**：Space 管理，支持切换和新建空间

### 8.3.1 侧边栏拖拽调整
```
┌──────────┐┬─────────────────────────────────────────┐
│          ││                                         │
│  侧边栏   ││  主内容区                                │
│          ││                                         │
│          ││                                         │
│          ├┤ ← 拖拽手柄 (4px宽，悬停变蓝)              │
│          ││                                         │
└──────────┘┴─────────────────────────────────────────┘
```

**拖拽规范**：
- **拖拽手柄**：侧边栏右边缘，宽度 4px
- **悬停状态**：手柄变蓝色 (`var(--primary)`)，鼠标变为 `col-resize`
- **最小宽度**：150px
- **最大宽度**：400px
- **默认宽度**：200px
- **双击手柄**：恢复默认宽度 200px
- **拖拽提示**：显示当前宽度数值（如 "220px"）

### 8.4 面板规格
- **面板数量**：1-4 个（可动态添加/删除）
- **最小宽度**：200px
- **默认宽度**：各面板平均分配
- **可调整**：支持拖拽调整面板宽度

### 8.5 面板 Tab 规格
- **每个面板独立管理 Tab**
- **每个 Tab 对应一个独立路径**
- **支持**：新建、关闭、左右切换
- **Tab 行右侧**：列表/树形视图切换图标
- **快捷键**：`Ctrl+T` 新建，`Ctrl+W` 关闭，`Ctrl+Tab` 切换面板

**交互方式**：
- **单击 Tab 行空白区域**：新建标签页
- **双击标签页**：关闭标签页（需确认对话框）
- **至少保留一个标签页**
- **列表/树形切换**：当前 Tab 独立切换

### 8.6 分栏布局（状态栏切换）

| 布局 | 图标 | 说明 |
|------|------|------|
| 1 分栏 | □ | 单面板，全屏显示 |
| 2 左右分栏 | ▯▯ | 左右两个面板 |
| 上下分栏 | ▯<br>▯ | 上下两个面板 |
| 3 左中右分栏 | ▯▯▯ | 左中右三个面板 |
| 上 2 下 1 | ▯▯<br>▔ | 上方两个面板，下方一个面板 |
| 上 1 下 2 | ▔<br>▯▯ | 上方一个面板，下方两个面板 |
| 4 分栏 | ▯▯<br>▯▯ | 上下两行，每行两个面板 |

### 8.7 状态栏
```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│ [多面板] [级联] | [🏠默认] [💼Work] [💻Dev] [+] | 4个面板·1个选中 | D:\...\ | [1] [2] [3] [4] │
└─────────────────────────────────────────────────────────────────────────────────────┘
  ↑ 模式切换          ↑ Space管理              ↑ 面板信息      ↑ 路径       ↑ 布局切换
```

**状态栏布局**：
- **最左侧**：分栏模式切换（多面板/级联）
- **左侧**：Space 空间切换（带图标）
- **中间**：面板数量、选中文件数、路径显示
- **右侧**：分栏布局切换（仅多面板模式显示）

### 8.8 分栏模式切换

| 模式 | 图标 | 说明 |
|------|------|------|
| 多面板模式 | ▯▯ | 每个面板独立浏览，支持 Tab |
| 级联分栏模式 | ▯▯▯ | Mac 访达风格，点击文件夹右侧展开新一栏 |

**多面板模式**：
- 每个面板独立管理 Tab
- 面板之间互不影响
- 适合同时浏览多个不同目录

**级联分栏模式**：
- 点击文件夹 → 右侧展开新一栏
- 每栏显示上一级目录的内容
- 适合深层目录浏览和文件移动

### 8.9 Space 空间管理

**概念**：每个 Space 保存一套独立的界面配置（面板布局、标签页、路径等）。

**使用场景**：
- **Work**：工作模式，打开项目文件夹、代码编辑器
- **Dev**：开发模式，打开多个代码目录、终端
- **Game**：游戏模式，打开游戏存档、模组文件夹
- **Test**：测试模式，打开测试数据、日志文件

**操作方式**：
- **状态栏**：点击 Space 按钮切换，点击 + 打开管理
- **侧边栏**：底部空间列表，点击切换
- **双击**：重命名 Space
- **删除**：下拉菜单中点击 ×（默认空间不可删除）

**Space 配置**：
- 面板布局（1-4 面板，布局方式）
- 每个面板的标签页和路径
- 侧边栏显示状态
- 分栏模式（多面板/级联）

### 8.10 视图模式切换

**Tab 行右侧图标**：
| 图标 | 模式 | 说明 |
|------|------|------|
| ≡ | 列表视图 | 表格形式展示文件，显示详细信息 |
| ☰ | 树形视图 | 文件夹树形结构，可展开/折叠子目录 |

**切换方式**：
- 每个面板独立切换，互不影响
- 点击图标立即生效
- 当前 Tab 独立切换

## 九、设计原则

### 9.1 工业/功能优先
专注于功能性和数据密度，采用等宽字体元素和柔和色调。避免 Q-Dir/TC 的陈旧感，同时保持专业工具的定位。

### 9.2 最小化装饰
让排版和间距完成所有工作，避免不必要的装饰。颜色稀少且有意义，仅用于状态和交互反馈。

### 9.3 网格纪律
严格的列对齐，可预测的布局。适合多面板文件管理器，提供一致的视觉体验。

### 9.4 Windows 原生集成
使用 Windows 10/11 系统字体和颜色，遵循 Fluent Design 语言，提供原生级的使用体验。

### 9.5 面板独立性
每个面板都是独立的文件浏览区域，可以同时打开不同的文件夹，通过标签页自由切换。

## 十一、动效规范

**原则**：最小功能化 — 只有帮助理解的过渡动画。

- **时长**：100-200ms
- **缓动**：ease-in-out
- **用途**：状态变化、展开/折叠、面板切换

---

## 十二、无障碍设计

- **对比度**：WCAG 2.1 AA 标准（4.5:1）
- **键盘导航**：完全支持 Tab/Enter/Arrow 键
- **屏幕阅读器**：适当的 ARIA 标签
- **焦点可见**：明显的焦点指示器

## 十五、拖拽交互

### 15.1 拖拽操作
| 操作 | 效果 |
|------|------|
| 拖拽文件到另一面板 | 移动文件到目标面板的当前目录 |
| Ctrl+拖拽文件到另一面板 | 复制文件到目标面板的当前目录 |
| 拖拽文件夹到另一面板 | 移动/复制文件夹及其内容 |
| 拖拽到同一面板 | 移动到同目录下的新位置 |

### 15.2 视觉反馈
```
拖拽时：
- 源文件行：半透明 + 虚线边框
- 目标面板：蓝色边框高亮
- 鼠标旁图标：
  - 移动：📄→
  - 复制：📄⊕

放下时：
- 目标面板：绿色边框闪烁
- 显示"已移动"/"已复制"提示
```

### 15.3 视觉规范
- **拖拽时源文件透明度**：0.5
- **目标区域高亮**：2px solid Primary
- **鼠标旁图标**：16x16px
- **放下反馈动画**：200ms ease-out
