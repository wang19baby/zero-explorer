## 一、产品概述

### 1.1 产品定位
Zero Explorer 是一款面向 Windows 10/11 的高性能文件管理器，专注于多面板布局和高效文件操作。

### 1.2 目标用户
- **核心用户**：开发者、设计师、IT 工程师等需要频繁处理文件的专业人士
- **扩展用户**：追求效率的 Windows 用户

### 1.3 核心价值
- **性能即功能**：毫秒级响应，零卡顿体验
- **多面板高效**：同时浏览多个目录，提升文件操作效率
- **现代美学**：符合 Windows 10/11 设计语言的现代化界面
- **渐进式复杂度**：新手友好，专家深度可挖

## 七、技术约束

### 7.1 必须满足
- 单文件便携运行
- 无 Electron/WebView/Qt 依赖
- 本地文件操作不依赖网络
- 支持路径输入框（Ctrl+L）快速跳转

### 7.2 优先考虑
- Rust 核心逻辑
- GPU 加速渲染
- 低内存占用
- 快速启动
