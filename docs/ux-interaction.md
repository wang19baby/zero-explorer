# Zero Explorer - UX 交互文档

**版本**: v1.0  
**日期**: 2026-08-31  
**产品**: Zero Explorer  
**平台**: Windows 10/11  

---

## 一、交互设计原则

### 1.1 核心原则
1. **性能即功能**：所有交互响应时间 < 100ms
2. **渐进式复杂度**：新手友好，专家深度可挖
3. **面板独立性**：每个面板独立浏览，互不干扰
4. **零负担体验**：界面元素最小化，让文件管理回归简单

### 1.2 交互模式
- **键盘优先**：所有功能可通过快捷键完成
- **鼠标辅助**：支持常见的鼠标操作
- **触控兼容**：支持 Windows 触控手势

## 二、导航交互

### 2.1 面包屑导航
**位置**：每个面板的 Tab 上方

**交互方式**：
| 操作 | 效果 | 反馈 |
|------|------|------|
| 单击层级 | 跳转到对应目录 | 面包屑更新，文件列表刷新 |
| 双击面包屑 | 切换为绝对路径输入框 | 显示输入框，隐藏面包屑 |
| 输入路径 + Enter | 跳转到指定路径 | 文件列表刷新 |
| Esc | 取消输入，恢复面包屑 | 显示面包屑，隐藏输入框 |

**状态变化**：
```
面包屑模式: D: > work_space > personal_workspace
                ↓ 双击
输入模式: [D:\work_space\personal_workspace          ]
                ↓ Enter
面包屑模式: D: > work_space > zero-explorer
```

### 2.2 侧边栏导航
**位置**：主内容区左侧（默认隐藏）

**交互方式**：
| 操作 | 效果 | 反馈 |
|------|------|------|
| Ctrl+Shift+B | 切换侧边栏显示/隐藏 | 侧边栏滑入/滑出 |
| 单击标签项 | 导航到对应文件夹 | 文件列表刷新，标签高亮 |
| 单击磁盘 | 导航到磁盘根目录 | 文件列表刷新 |
| 单击最近访问项 | 导航到对应文件/文件夹 | 文件列表刷新 |
| 单击添加文件夹 | 弹出文件夹选择对话框 | 选择后添加到标签 |
| 单击×按钮 | 删除标签项 | 标签项移除 |
| 单击空间项 | 切换 Space | 界面配置更新 |
| 单击添加空间 | 创建新 Space | 弹出名称输入框 |

**标签管理**：
- 拖拽标签项可调整顺序
- 右键菜单：重命名、删除、移动到分组
- 支持多选批量操作

**Space 管理**：
- 位置：侧边栏底部
- 显示所有 Space 列表
- 当前 Space 高亮显示
- 支持新建、切换、删除（默认 Space 不可删除）

### 2.3 状态栏导航
**位置**：窗口底部

**状态栏布局**：
```
[多面板] [级联] | [🏠默认] [💼Work] [💻Dev] [+] | 4个面板·1个选中 | D:\...\ | [1] [2] [3] [4]
```

**交互方式**：
| 操作 | 效果 | 反馈 |
|------|------|------|
| 单击模式图标 | 切换多面板/级联模式 | 模式立即变化 |
| 单击 Space 按钮 | 切换空间 | 界面配置更新 |
| 双击 Space 按钮 | 重命名空间 | 弹出名称输入框 |
| 单击 + 按钮 | 打开空间管理 | 显示下拉菜单 |
| 单击路径 | 复制路径到剪贴板 | 显示"已复制!"提示 |
| 单击布局图标 | 切换分栏布局（仅多面板） | 布局立即变化 |

### 2.4 地址栏交互
**位置**：面包屑导航切换

**交互流程**：
```
用户按 Ctrl+L
    ↓
面包屑切换为路径输入框
    ↓
显示下拉菜单：
├── 历史路径
│   ├── D:\work_space\personal_workspace\web-app
│   └── D:\work_space\shared\projects
└── 已打开的 Tab
    ├── 面板1: src (D:\work_space\...\src)
    ├── 面板2: target (D:\work_space\...\target)
    ├── 面板3: 2026 (E:\backup\2026)
    └── 面板4: Desktop (C:\Users\wang\Desktop)
    ↓
用户输入路径或选择选项
    ↓
跳转到目标目录 / 取消 (Esc)
```

**快捷键**：
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+L` | 激活地址栏 |
| `Enter` | 跳转到输入路径 |
| `Esc` | 取消输入，恢复面包屑 |
| `↑↓` | 在下拉菜单中导航 |

## 三、面板交互

### 3.1 面板管理
**创建面板**：
- 快捷键：`Ctrl+Shift+T`
- 菜单：文件 → 新建面板
- 拖拽：拖拽标签到窗口边缘

**关闭面板**：
- 快捷键：`Ctrl+Shift+W`
- 菜单：文件 → 关闭面板
- 确认：至少保留一个面板

**调整面板**：
- 拖拽面板边框调整宽度
- 双击边框恢复默认宽度
- 最小宽度：200px

### 3.2 面板布局
**7 种布局模式**：
1. **1 分栏**：单面板，全屏显示
2. **2 左右分栏**：左右两个面板
3. **上下分栏**：上下两个面板
4. **3 左中右分栏**：左中右三个面板
5. **上 2 下 1**：上方两个面板，下方一个面板
6. **上 1 下 2**：上方一个面板，下方两个面板
7. **4 分栏**：上下两行，每行两个面板

**切换方式**：
- 状态栏图标点击
- 快捷键：`Ctrl+1` 到 `Ctrl+7`
- 菜单：视图 → 布局

### 3.3 分栏模式
**多面板模式**：
- 每个面板独立管理 Tab
- 面板之间互不影响
- 适合同时浏览多个不同目录

**级联分栏模式**：
- 点击文件夹 → 右侧展开新一栏
- 每栏显示上一级目录的内容
- 适合深层目录浏览和文件移动

**切换方式**：
- 状态栏模式图标
- 快捷键：`Ctrl+Shift+M`

## 四、标签页交互

### 4.1 标签页操作
**创建标签页**：
- 快捷键：`Ctrl+T`
- 单击标签行空白区域
- 拖拽文件夹到标签栏

**关闭标签页**：
- 快捷键：`Ctrl+W`
- 双击标签页（需确认）
- 右键菜单：关闭

**切换标签页**：
- 快捷键：`Ctrl+Tab`
- 单击标签页
- 快捷键：`Ctrl+Shift+Tab` 反向切换

**标签页状态**：
- 选中：白色背景，底部蓝色边框
- 悬停：白色背景
- 默认：#F3F3F3 背景

### 4.2 标签页管理
**固定标签页**：
- 拖拽标签页到最左侧
- 右键菜单：固定/取消固定
- 固定标签页不显示关闭按钮

**重命名标签页**：
- 右键菜单：重命名
- 双击标签页文字（非关闭按钮）
- 输入新名称 + Enter

**标签页分组**：
- 拖拽标签页到另一个标签页上
- 创建标签页组
- 组内标签页可批量操作

### 4.3 视图模式切换
**Tab 行右侧图标**：
| 图标 | 模式 | 说明 |
|------|------|------|
| ≡ | 列表视图 | 表格形式展示文件，显示详细信息 |
| ☰ | 树形视图 | 文件夹树形结构，可展开/折叠子目录 |

**交互方式**：
| 操作 | 效果 | 反馈 |
|------|------|------|
| 单击列表图标 | 切换为列表视图 | 图标高亮，文件列表刷新 |
| 单击树形图标 | 切换为树形视图 | 图标高亮，显示文件夹树 |

**视图特点**：
- 每个面板独立切换，互不影响
- 当前 Tab 独立切换
- 切换后保持当前选中文件

## 五、文件列表交互

### 5.1 文件选择
**单选**：
- 单击文件行
- 键盘：上下箭头

**多选**：
- Ctrl+单击：追加选择
- Shift+单击：范围选择
- Ctrl+A：全选

**选择状态**：
- 悬停：Primary Light 背景
- 选中：Primary 背景，白色文字

### 5.3 拖拽交互
**拖拽操作**：
| 操作 | 效果 | 反馈 |
|------|------|------|
| 拖拽文件到另一面板 | 移动文件 | 目标区域蓝色边框高亮 |
| Ctrl+拖拽文件到另一面板 | 复制文件 | 目标区域蓝色边框高亮 |
| 拖拽文件夹到另一面板 | 移动/复制文件夹 | 目标区域蓝色边框高亮 |
| 拖拽到同一面板 | 移动到同目录 | 源位置显示插入线 |

**视觉反馈流程**：
```
开始拖拽
    ↓
源文件行：半透明 + 虚线边框
    ↓
经过另一面板时：
├── 目标面板：2px solid Primary 边框
├── 鼠标旁图标：
│   ├── 移动：📄→
│   └── 复制：📄⊕ (Ctrl 按下时)
└── 文件夹显示展开箭头
    ↓
放下文件：
├── 目标面板：绿色边框闪烁
├── 显示"已移动"/"已复制"提示
└── 刷新文件列表
```

**拖拽规范**：
- **拖拽延迟**：200ms（防止误操作）
- **源文件透明度**：0.5
- **目标高亮颜色**：Primary
- **放下反馈动画**：200ms ease-out
- **最小拖拽距离**：5px

### 5.2 文件操作
**打开文件**：
- 双击文件
- Enter 键
- 右键菜单：打开

**打开文件夹**：
- 双击文件夹
- Enter 键
- 右键菜单：打开

**复制**：
- Ctrl+C
- 右键菜单：复制
- 拖拽到另一面板（默认复制）

**移动**：
- Ctrl+X
- 右键菜单：移动
- 拖拽到另一面板 + Shift

**删除**：
- Delete 键
- 右键菜单：删除
- 确认对话框（可配置）

**重命名**：
- F2 键
- 右键菜单：重命名
- 直接编辑文件名

**新建**：
- Ctrl+Shift+N：新建文件夹
- 右键菜单：新建

### 5.3 文件排序
**排序方式**：
- 单击列标题：按该列排序
- 右键菜单：排序方式
- 快捷键：`Ctrl+1` 到 `Ctrl+5`

**排序列**：
1. 名称
2. 类型
3. 大小
4. 修改时间
5. 创建时间

**排序方向**：
- 单击列标题：切换升序/降序
- 图标：↑ 升序，↓ 降序

### 5.4 文件过滤
**快速过滤**：
- Ctrl+F：激活过滤框
- 输入关键字：实时过滤
- Esc：取消过滤

**过滤方式**：
- 文件名匹配
- 类型匹配
- 大小匹配
- 日期匹配

## 十二、错误处理

### 12.1 错误类型
1. **文件不存在**：提示文件已被删除或移动
2. **权限不足**：提示需要管理员权限
3. **磁盘满**：提示磁盘空间不足
4. **文件被占用**：提示文件正在被使用
5. **网络错误**：提示网络连接问题

### 12.2 错误提示
- **位置**：状态栏或弹窗
- **内容**：错误原因和解决方案
- **操作**：重试、取消、忽略

### 12.3 错误恢复
- **自动重试**：网络错误自动重试
- **撤销操作**：支持撤销文件操作
- **备份恢复**：重要操作前自动备份
