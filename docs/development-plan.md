## 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      应用层 (Application)                     │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│  │  面板   │ │  标签页  │ │  侧边栏  │ │  状态栏  │          │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘          │
├─────────────────────────────────────────────────────────────┤
│                      UI 框架层 (UI Framework)                │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│  │  布局   │ │  渲染   │ │  输入   │ │  主题   │          │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘          │
├─────────────────────────────────────────────────────────────┤
│                      系统层 (System)                         │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐          │
│  │文件系统 │ │  窗口   │ │  GPU    │ │  配置   │          │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘          │
└─────────────────────────────────────────────────────────────┘
```

## Phase 0: 地基（0-3 个月）

**目标**：验证核心架构可行性，输出可在 Windows 运行的最小原型

### 0.1 项目初始化
**预计时间**：1 周

| 任务 | 描述 | 依赖 |
|------|------|------|
| Cargo 项目创建 | 初始化 Rust 项目，配置依赖 | 无 |
| 项目结构设计 | 分层架构：`core/` `ui/` `fs/` `app/` | 无 |
| 依赖选型 | winit, wgpu, tokio, serde 等 | 无 |
| CI/CD 搭建 | GitHub Actions 自动构建 | 无 |

**依赖库选型**：
```toml
[dependencies]
# 窗口管理
winit = "0.29"           # 跨平台窗口
winapi = { version = "0.3", features = ["winuser"] }  # Windows API

# GPU 渲染
wgpu = "0.19"            # GPU 抽象层
pollster = "0.3"         # 异步运行时

# 异步运行时
tokio = { version = "1", features = ["full"] }

# 序列化
serde = { version = "1", features = ["derive"] }
serde_json = "1"

# 日志
log = "0.4"
env_logger = "0.10"
```
